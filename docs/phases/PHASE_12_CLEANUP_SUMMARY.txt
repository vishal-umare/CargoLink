3. REFACTORING DONE
--------------------------------------------------------------------------------
The final 5 files that were still dependent on Supabase have been refactored to use the local Node.js API and/or mocked local state (where backend routes are not yet implemented):

    - Auth now relies 100% on `apiFetch` to `/auth/login` and `/auth/register`.

  ✓ components/maps/RouteMap.tsx & components/maps/MapboxLocationPicker.tsx
    - Removed `supabase.auth.getSession()` and Supabase Edge Function calls.
    - Added `app.get('/api/config/mapbox')` to the Node.js `server.js` to serve the token.
    - Components now fetch mapbox token via `apiFetch('/config/mapbox')`.

  ✓ pages/shipper/LoadHistory.tsx
    - Replaced the Supabase `Tables<'loads'>` import with a local interface.

  ✓ pages/driver/RideMap.tsx
    - Replaced direct `supabase.from('loads')` queries with `apiFetch('/loads')`.
    - Replaced `supabase.update({ status: 'completed' })` with `apiFetch('/loads/:id/complete')`.

  ✓ pages/driver/Profile.tsx & pages/shipper/Profile.tsx
    - Removed Supabase imports.
    - Wrapped `handleSaveProfile` with mock API delays for now (since there is no `/api/profile` PUT route yet), allowing the UI to remain fully functional without crashing.
